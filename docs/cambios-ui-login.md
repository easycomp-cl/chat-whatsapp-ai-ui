# Login — layout split desktop

## Qué cambió

- `/login` en desktop usa un layout de dos columnas (panel de marca + formulario), con el mismo flujo: email, contraseña, ingresar, recuperar y crear cuenta.
- Colores easyCOMP: verde eléctrico `#22d3a3` / `#0d9488` y rojo `#c4121a`.
- En desktop el panel izquierdo rota 3 slides (WhatsApp, bandeja bot/humano, conocimiento) cada 8 s, con fundido lento. Los puntos cambian de slide.
- En móvil se oculta el panel izquierdo y queda el formulario centrado.
