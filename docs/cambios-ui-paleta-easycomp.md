# Paleta easyCOMP (rojo + verde eléctrico)

## Qué cambió

Se quitaron morados y violetas de login, app y landing. La estructura de tokens se mantiene (`--chat-primary`, `--chat-accent`, landing, sidebar).

Colores tomados del modo oscuro de [easycomp.cl](https://easycomp.cl):

| Uso | Color |
|-----|--------|
| Verde eléctrico (CTA, acentos claros) | `#22d3a3` |
| Verde de texto/botones en UI clara | `#0d9488` |
| Rojo de marca | `#c4121a` |
| Teal secundario | `#2dd4bf` |

`--chat-accent` pasó de coral `#ff7a55` a rojo `#c4121a`. El coral queda solo donde marca “humano / pendiente” para no confundirlo con error.
